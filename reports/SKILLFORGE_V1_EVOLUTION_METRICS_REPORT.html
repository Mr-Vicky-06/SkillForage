Multi-Channel Ranking Architecture

Reciprocal Rank Fusion Equation:

RRF(d) = ∑ [ w_c / (60.0 + rank_c(d)) ]

• Lexical Channel (w=1.0): FTS5 BM25 match

• Graph Channel (w=0.85): CTE proximity

• Technology Channel (w=0.75): Project stack match

• Tool Affinity (w=0.50): Active local tool boost
